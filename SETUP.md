# Publish the updated Aaravpp profile README

1. Replace the repository's `README.md` and `assets/` folder with the files in this package.
2. Also upload the `.github/` and `scripts/` folders to the repository root. These are required to generate the statistics automatically.
3. Commit and push to the `main` branch.
4. Open the repository's **Actions** tab. Run **Update profile statistics and contribution snake** once using **Run workflow** if it has not started automatically.
5. After the workflow succeeds, refresh your GitHub profile. It will update the local stats SVGs daily.

The stats and language cards are generated locally from GitHub's public API by GitHub Actions. The contribution snake is generated by Platane/snk. The initial cards are placeholders until the first successful workflow run.

The contribution stats card (total contributions, current streak, longest streak) is generated from GitHub's GraphQL contribution calendar by the same scheduled workflow. It displays dashes if GitHub does not return contribution data to the workflow token.
